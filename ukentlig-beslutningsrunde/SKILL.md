# Ukentlig beslutningsrunde

Goal: one short decision list for the owner per week instead of many scattered questions.

## Steps
1. **Collect.** From each team (via 1:1 messages or the week's reports), gather open items that need the owner: new skill proposals, corrections and bookings, spending, filings, missing documents or access, and blockers.
2. **Check for duplicates.** Before listing an item, check whether another assistant has already asked the owner the same thing this week. If so, don't ask again. Point to the existing question and add only what is new.
3. **Merge.** Combine overlapping proposals into one (e.g. two reconciliation skills become one shared skill with two users). Note who owns each item.
4. **Write the list.** One line per item: name, owner, what it does or decides, and why now. Put blockers (missing access, documents, agreements) as separate items. End with a simple way to answer (all / a selection / none).
5. **Send once** to the owner in a 1:1 chat. Never send to outside parties.
6. **Record decisions.** When the owner answers, mark each item approved, declined or parked, with the date, and tell each item owner the result 1:1. Approved skills are created by their owner without duplicates. Nothing is created, booked, paid or filed before an explicit yes.
7. **Carry over.** Unanswered items roll into next week's list. Don't re-ask an item the owner declined or dismissed.

## Rules
- Never invent numbers or decisions. Quote the team's own figures and sources.
- Keep financial and health data off public pages.
- One question per item, and plain language.
