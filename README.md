# agent-skills

Generic agent skill templates: one folder per skill, each with a `SKILL.md` (plus occasional templates, examples or reference files). They are reusable starting points for AI coding/ops agents, not tied to any private data. Example companies and people in sample outputs are fictional.

Some skills are adapted from upstream open-source skill collections and keep their own `LICENSE` file; that license applies to that folder.
